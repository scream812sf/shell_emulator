# Эмулятор командной строки ОС (Вариант №27)

## 1. Общее описание
Проект представляет собой прототип эмулятора оболочки UNIX-подобной 
операционной системы с графическим интерфейсом пользователя (GUI).
Эмулятор взаимодействует с пользователем в режиме REPL (Read-Eval-Print Loop),
обрабатывает введенные команды, выполняет их разбор и возвращает результат
на экран терминала.

## 2. Описание функций и настроек
### Особенности интерфейса
- Заголовок окна: формируется динамически на основе реальных данных 
  системы в формате: Эмулятор [username@hostname].
- Графический интерфейс: реализован на базе библиотеки Tkinter.

### Модули и функции
- src/emulator.py:
  - CommandExecutor: основной класс логики исполнения команд.
  - parse_input(user_input): парсер командной строки, разделяющий строку 
    на имя команды и аргументы по пробельным символам.
  - execute(user_input): маршрутизация и запуск обработчиков команд.
  - _cmd_ls(args): команда-заглушка ls, выводит переданные аргументы.
  - _cmd_cd(args): команда-заглушка cd, выводит аргументы и проверяет их 
    количество (не более одного аргумента).
  - _cmd_exit(args): команда exit, завершает работу приложения без аргументов.
- src/gui.py:
  - EmulatorGUI: класс построения графического интерфейса.
  - _build_widgets(): инициализация текстовой области вывода и поля ввода.
  - _handle_input(event): перехват нажатия Enter и передача ввода исполнителю.

## 3. Сборка проекта и запуск тестов
Для работы приложения требуется Python версии 3.10 или выше. Дополнительные
внешние зависимости не требуются (используются стандартные библиотеки).

Запуск модульных тестов:
python -m unittest discover tests

Запуск приложения на Windows:
run.bat
или через прямой запуск модуля:
python -m src.gui

Запуск приложения на Linux / macOS:
./run.sh
или:
python3 -m src.gui

## 4. Примеры использования
Ниже приведены примеры ввода команд в эмуляторе и получаемого вывода:

Команда ls (вызов заглушки):
$ ls -l /usr/bin
ls: вызвана с аргументами [-l /usr/bin]

Команда cd (вызов заглушки):
$ cd /home/user
cd: вызвана с аргументами [/home/user]

Ошибка: неверные аргументы команды cd:
$ cd dir1 dir2
Ошибка: команда cd принимает не более одного аргумента

Ошибка: неизвестная команда:
$ unknown_cmd arg1
Ошибка: неизвестная команда 'unknown_cmd'

Команда exit (завершение сеанса):
$ exit

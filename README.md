# Эмулятор командной строки ОС (Вариант №27)

## 1. Общее описание
Проект представляет собой прототип эмулятора оболочки UNIX-подобной
операционной системы с графическим интерфейсом на базе библиотеки Tkinter.
На этапе 2 реализована параметризация приложения через аргументы командной
строки, отладочный вывод параметров конфигурации при старте эмулятора,
служебная команда conf-dump для вывода настроек в формате «ключ-значение»,
а также возможность выполнения стартовых скриптов с поддержкой
однострочных комментариев (символ #) и имитацией диалога с пользователем.

## 2. Описание функций и настроек
### Параметры командной строки
- --vfs <путь>: физический путь к расположению виртуальной файловой системы.
- --script <путь>: путь к файлу стартового скрипта с командами эмулятора.

### Поддерживаемые команды
- ls [аргументы]: команда-заглушка вывода содержимого директории.
- cd [путь]: команда-заглушка смены каталога (принимает не более одного аргумента).
- conf-dump: вывод всех заданных параметров конфигурации в формате ключ-значение.
- exit: завершение работы приложения.
- \# комментарий: строки, начинающиеся с символа #, воспринимаются как комментарии и игнорируются.

### Архитектура модулей
- src/emulator.py: класс CommandExecutor инкапсулирует разбор командной
  строки, хранение переданных параметров конфигурации и логику команд.
- src/gui.py: класс ShellGUI строит интерфейс на Tkinter, формирует
  заголовок окна Эмулятор [username@hostname], выводит отладочные параметры
  при инициализации и реализует построчное исполнение команд стартового скрипта.

## 3. Сборка проекта и запуск тестов
Для работы эмулятора требуется Python версии 3.10 или выше без сторонних
зависимостей.

Запуск модульных тестов:
python -m unittest discover tests

Запуск эмулятора с полным набором параметров (Windows):
scripts\test_run_all.bat

Запуск эмулятора в минимальном режиме (Windows):
scripts\test_run_minimal.bat

Прямой запуск через модуль Python:
python -m src.gui --vfs "vfs.zip" --script "scripts/startup.txt"

## 4. Примеры использования
- Запуск служебной команды вывода параметров конфигурации:
$ conf-dump
vfs_path: vfs.zip
script_path: scripts/startup.txt

- Попытка передачи лишних аргументов в conf-dump:
$ conf-dump extra_param
Ошибка: команда conf-dump не принимает аргументов

- Игнорирование комментариев в интерактивном режиме и скриптах:
$ # Это строка комментария

- Обработка ошибок при отсутствии стартового скрипта:
Ошибка: стартовый скрипт 'not_found.txt' не найден

- Проверка валидации аргументов команды перехода:
$ cd dir1 dir2
Ошибка: команда cd принимает не более одного аргумента

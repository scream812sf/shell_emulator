# Эмулятор командной строки ОС (Вариант №27)

## 1. Общее описание
Проект представляет собой эмулятор оболочки UNIX-подобной операционной
системы с графическим интерфейсом на базе библиотеки Tkinter.
На этапе 4 поддержаны основные утилиты командной строки: uptime для
получения времени работы эмулятора и tail для просмотра содержимого
файлов из виртуальной файловой системы (VFS) в оперативной памяти.
VFS функционирует без распаковки zip-архива на физический диск.
Сохранена вся функциональность предыдущих этапов: навигация (ls, cd),
конфигурация (conf-dump) и исполнение стартовых сценариев.

## 2. Описание функций и настроек
### Параметры командной строки
- --vfs <путь>: путь к zip-архиву виртуальной файловой системы.
- --script <путь>: путь к файлу стартового скрипта с командами.

### Поддерживаемые команды
- ls [путь]: вывод содержимого каталога из VFS (текущего или заданного).
- cd [путь]: смена рабочей директории (поддерживает /, ., ..).
- uptime: вывод времени непрерывной работы эмулятора с момента запуска.
- tail [-n строк] <файл>: вывод последних строк текстового файла из VFS.
- conf-dump: вывод текущих параметров конфигурации в формате ключ: значение.
- exit: закрытие графического окна и завершение работы программы.
- # комментарий: игнорирование строк-комментариев в скриптах и REPL.

### Архитектура модулей
- src/vfs.py: класс VirtualFileSystem загружает архив в память, парсит
  иерархию папок и читает байтовое/текстовое содержимое файлов.
- src/emulator.py: класс CommandExecutor обрабатывает ввод, парсит аргументы,
  рассчитывает время для uptime и выполняет срезы строк для tail.
- src/gui.py: класс ShellGUI отвечает за окно Tkinter, вывод параметров,
  строку приглашения user@host:path$ и запуск скриптов.
- make_vfs.py: вспомогательный генератор тестового zip-архива.

## 3. Сборка проекта и запуск тестов
Для работы эмулятора необходим Python версии 3.10 или выше.

Генерация тестовой файловой системы:
python make_vfs.py

Запуск модульных тестов:
python -m unittest discover tests

Запуск эмулятора со всеми параметрами (Windows):
scripts\test_run_all.bat

Запуск эмулятора в минимальном режиме (Windows):
scripts\test_run_minimal.bat

Прямой запуск через модуль Python:
python -m src.gui --vfs "virtual_fs.zip" --script "scripts/startup.txt"

## 4. Примеры использования
- Вывод времени непрерывной работы эмулятора:
user@host:/$ uptime
up 00:00:15

- Просмотр последних строк текстового файла по умолчанию (10 строк):
user@host:/$ tail readme.txt
Welcome to VFS!
Variant 27 Shell Emulator.

- Просмотр заданного числа строк с помощью параметра -n:
user@host:/$ tail -n 2 readme.txt
Welcome to VFS!
Variant 27 Shell Emulator.

user@host:/$ tail -n 5 long.txt
Line 11
Line 12
Line 13
Line 14
Line 15

- Навигация по каталогам и чтение вложенных файлов:
user@host:/$ cd home/user
user@host:/home/user$ tail notes.txt
1. Task one
2. Task two

- Обработка ошибок при работе с файлами:
user@host:/$ tail invalid.txt
tail: 'invalid.txt': нет такого файла

user@host:/$ tail etc
tail: 'etc': это каталог

- Обработка неверных аргументов команды uptime:
user@host:/$ uptime now
Ошибка: команда uptime не принимает аргументов

# Эмулятор командной строки ОС (Вариант №27)

## 1. Общее описание
Проект представляет собой эмулятор оболочки UNIX-подобной операционной
системы с графическим интерфейсом на базе библиотеки Tkinter.
На этапе 5 поддержаны команды модификации виртуальной файловой системы
(VFS) в оперативной памяти: rmdir для удаления пустых каталогов и vfs-load
для динамической загрузки нового образа файловой системы с диска.
Все модификации происходят исключительно в оперативной памяти без
изменения физических архивов. В эмуляторе в полном объеме функционируют
команды ls, cd, uptime, tail, conf-dump, exit, а также поддержка
стартовых скриптов и комментариев.

## 2. Описание функций и настроек
### Параметры командной строки
- --vfs <путь>: путь к zip-архиву виртуальной файловой системы.
- --script <путь>: путь к файлу стартового скрипта с командами.

### Поддерживаемые команды
- ls [путь]: вывод содержимого каталога из VFS (текущего или заданного).
- cd [путь]: смена рабочей директории (поддерживает /, ., ..).
- uptime: вывод времени работы эмулятора с момента старта (up ЧЧ:ММ:СС).
- tail [-n строк] <файл>: вывод последних строк текстового файла.
- rmdir <каталог>: удаление пустой директории из памяти VFS.
- vfs-load <путь>: загрузка новой файловой системы из zip-архива.
- conf-dump: вывод текущих параметров конфигурации (ключ: значение).
- exit: закрытие окна и завершение работы программы.
- # комментарий: игнорирование строк-комментариев.

### Архитектура модулей
- src/vfs.py: класс VirtualFileSystem инкапсулирует дерево файлов/папок
  в памяти, чтение содержимого, удаление каталогов и перезагрузку VFS.
- src/emulator.py: класс CommandExecutor связывает команды пользователя
  с операциями над VFS и рассчитывает системное время.
- src/gui.py: класс ShellGUI отвечает за отрисовку Tkinter, динамическое
  приглашение user@host:path$ и построчное исполнение сценариев.
- make_vfs.py: утилита генерации тестовых zip-архивов для демонстрации.

## 3. Сборка проекта и запуск тестов
Для работы эмулятора требуется Python версии 3.10 или выше.

Генерация тестовых архивов:
python make_vfs.py

Запуск модульных тестов:
python -m unittest discover tests

Запуск эмулятора со всеми параметрами (Windows):
scripts\test_run_all.bat

Запуск эмулятора в минимальном режиме (Windows):
scripts\test_run_minimal.bat

Прямой запуск через модуль Python:
python -m src.gui --vfs "virtual_fs.zip" --script "scripts/startup.txt"

## 4. Примеры использования
- Удаление пустого каталога:
user@host:/$ ls
empty_dir
readme.txt
user@host:/$ rmdir empty_dir
user@host:/$ ls
readme.txt

- Попытка удаления непустого каталога:
user@host:/$ rmdir home
rmdir: 'home': каталог не пуст

- Загрузка новой VFS с диска и чтение файлов нового образа:
user@host:/$ vfs-load secondary_vfs.zip
VFS успешно загружена из 'secondary_vfs.zip'
user@host:/$ ls
backup_info.txt
var
user@host:/$ tail backup_info.txt
This is secondary VFS archive loaded at runtime.

- Проверка конфигурации после загрузки нового архива:
user@host:/$ conf-dump
vfs_path: secondary_vfs.zip
script_path: scripts/startup.txt

# Эмулятор командной строки ОС (Вариант №27)

## 1. Общее описание
Проект представляет собой эмулятор оболочки UNIX-подобной операционной
системы с графическим интерфейсом на базе библиотеки Tkinter.
На этапе 3 реализована полноценная виртуальная файловая система (VFS)
в оперативной памяти на основе архива формата zip. Образ файловой системы
загружается при старте приложения без распаковки на физический диск.
Обеспечена поддержка команд навигации (cd) и просмотра каталогов (ls),
а также динамическое отображение текущего пути в строке приглашения
пользователя. Сохранена функциональность конфигурации (conf-dump),
стартовых скриптов с комментариями и отладочного вывода параметров.

## 2. Описание функций и настроек
### Параметры командной строки
- --vfs <путь>: путь к zip-архиву виртуальной файловой системы.
- --script <путь>: путь к файлу стартового скрипта с командами.

### Поддерживаемые команды
- ls [путь]: вывод содержимого директории из VFS (текущей или заданной).
- cd [путь]: перемещение по каталогам VFS (поддерживает /, ., ..).
- conf-dump: вывод параметров конфигурации в формате «ключ: значение».
- exit: завершение работы эмулятора и закрытие графического окна.
- \# комментарий: строки, начинающиеся с символа #, игнорируются.

### Архитектура модулей
- src/vfs.py: класс VirtualFileSystem реализует модель каталогов и файлов
  в оперативной памяти на базе zip-архива, канонизацию путей и навигацию.
- src/emulator.py: класс CommandExecutor обрабатывает команды и связывает
  их логику с виртуальной файловой системой.
- src/gui.py: класс ShellGUI отвечает за отрисовку Tkinter, динамическое
  приглашение user@host:path$ и построчное исполнение стартовых скриптов.
- make_vfs.py: вспомогательная утилита для генерации тестового zip-образа.

## 3. Сборка проекта и запуск тестов
Для работы эмулятора требуется Python версии 3.10 или выше без сторонних
зависимостей.

Генерация тестового архива VFS:
python make_vfs.py

Запуск модульных тестов:
python -m unittest discover tests

Запуск эмулятора со всеми параметрами (Windows):
scripts\test_run_all.bat

Запуск эмулятора в минимальном режиме (Windows):
scripts\test_run_minimal.bat

Прямой запуск через модуль Python:
python -m src.gui --vfs "virtual_fs.zip" --script "scripts/startup.txt"

## 4. Примеры использования
- Вывод содержимого текущей директории в VFS:
user@host:/$ ls
etc
home
readme.txt

- Переход в подкаталог и просмотр вложенных файлов:
user@host:/$ cd home/user
user@host:/home/user$ ls
notes.txt
test.txt

- Просмотр каталога по абсолютному пути:
user@host:/home/user$ ls /etc
config.cfg

- Возврат на уровень выше и в корень:
user@host:/home/user$ cd ..
user@host:/home$ cd /
user@host:/$

- Обработка ошибок перехода в несуществующий каталог:
user@host:/$ cd invalid_folder
cd: 'invalid_folder': нет такого файла

- Попытка перехода в обычный файл:
user@host:/$ cd readme.txt
cd: 'readme.txt': не каталог

- Просмотр параметров конфигурации эмулятора:
user@host:/$ conf-dump
vfs_path: virtual_fs.zip
script_path: scripts/startup.txt
